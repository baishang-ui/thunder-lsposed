# 按功能组织的样式设置

独立 App 与系统设置嵌入页使用相同的功能层级与参数：

| 功能页 | 同级样式卡片 |
| --- | --- |
| 流体云 | 流体云样式（胶囊、展开卡片、应用色）、锁屏样式、通知中心样式 |
| 通控中心 | 背景、通知条样式、通知横幅样式、1×1 磁贴、1×2 磁贴、音量／亮度条、音乐磁贴 |
| 音量面板 | 音量面板样式，内含动画、展开方式、尺寸及两种材质 |
| 状态栏 | 布局与间距、时钟样式、图标样式与显示 |
| 手势条 | 手势条样式，内含显示、占位、尺寸、位置、材质与颜色 |

每张卡片的标题行提供独立样式开关。关闭时该范围跟随系统并收起参数，保存的数值、颜色和细项开关保留；再次开启恢复。将最后一个细项设为系统默认不会自动关闭或收起整张卡片。没有流体云页面级父开关，三个样式互不依赖。

独立 App 使用现有 Miuix 卡片和 Kyant0 LiquidToggle；系统设置使用宿主 COUI Preference 分组和开关。状态栏图标方案沿用原有重启 SystemUI 的要求。

JSON 导出为 v23，继续支持 v3–v22 导入。旧的共用磁贴参数在迁移时复制到四种磁贴；旧的流体云卡片圆角分别迁移到锁屏和通知中心；旧的通知材质作为通知中心流体云的初始值。迁移后各组独立保存。滑条进度与图标保留原生颜色及对比度。

关闭组在创建 HookConfig 快照时停用修改，界面与持久化层保留原参数。共享的流体云颜色资源与卡片圆角资源在新分组模式中保持原生，由有归属视图的 Hook 选择材质和形状，避免跨组影响。

验证包含配置往返、旧版本迁移、两端显隐、原生材质与圆角恢复和 Hook fixtures。没有连接设备时，合成检查与构建不能替代 ColorOS 真机视觉验收。
