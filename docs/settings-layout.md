# 按功能组织的样式设置

独立 App 与系统设置嵌入页共用参数目录、默认值和保存逻辑，但各自保留适合其场景的导航。

独立 App 使用 COUI Compose 2.0。底部三个入口是「功能」「常用」「管理」：功能首页用大卡片和两列卡片直接进入编辑；常用页显示固定的开关、数值和最近调整；管理页收纳外观、备份、连接权限和运行报告。系统设置内嵌页继续使用宿主原生 COUI 布局。

| 功能页 | 顶部标签 |
| --- | --- |
| 流体云 | 胶囊、展开卡片、动效、锁屏、通知中心 |
| 通控中心 | 背景、通知、横幅、磁贴；磁贴标签内切换四种类型 |
| 音量面板 | 尺寸、动效、材质 |
| 状态栏 | 布局、时钟、图标 |
| 手势条 | 显示、尺寸、材质 |

参数直接在页面内编辑，不再用底部弹层承载整组参数。样式开关决定当前组是否应用；关闭后仍可编辑和保存，不改变系统当前效果。将最后一个细项设为系统默认不会自动关闭整组。流体云的三个样式互不依赖。

顶栏搜索可定位到具体参数，并自动切换相应的 COUI 分段标签与磁贴类型。长按开关或数值设置可固定到常用；移除固定项不改动参数。修改过的设置旁有历史图标，可选取此轮使用期间的旧值。固定项和最近调整只留在本机，不写入备份。数值支持滑动和精确输入，颜色支持常用色、调色和 HEX。旧界面的雾度、折射与圆角字段仅为既有 JSON 兼容而保留；状态栏图标方案仍需重启 SystemUI。

JSON 导出为 v25，继续支持 v3–v24 导入。旧的共用磁贴参数在迁移时复制到四种磁贴；旧的流体云卡片圆角分别迁移到锁屏和通知中心；旧的通知材质作为通知中心流体云的初始值。迁移后各组独立保存。滑条进度与图标保留原生颜色及对比度。

关闭组在创建 HookConfig 快照时停用修改，界面与持久化层保留原参数。共享的流体云颜色资源与卡片圆角资源在新分组模式中保持原生，由有归属视图的 Hook 选择材质和形状，避免跨组影响。

验证包含配置往返、旧版本迁移、两端显隐、原生材质与圆角恢复和 Hook fixtures。没有连接设备时，合成检查与构建不能替代 ColorOS 真机视觉验收。
