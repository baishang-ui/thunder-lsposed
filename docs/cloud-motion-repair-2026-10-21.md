# 流体云动画与原生交互修复（2026-10-21）

本次针对状态栏流体云的六项反馈修复；原生业务数据、手势与卡片窗口生命周期仍由宿主负责。Hook 调整宿主视图，不改变独立 App 的 MIUIx / Liquid Glass 组件体系。

## 联动动画

首卡由胶囊连续形变展开，后续卡片从首卡下方移出；收起时后续卡片向首卡下方汇拢，首卡同步变回胶囊。后续卡片的收拢锚点逐帧读取首卡当前矩形，避免固定的大卡片锚点在胶囊处留下偏移。中断和反转继承当前几何、速度与展开程度。

旧运动只对收起的宽高和圆角抑制回弹，坐标仍会越过胶囊目标。现在收起的整副矩形使用一致的临界阻尼响应，并对材质和卡片移出程度采用单向进度，避免回弹触发卡片消失后再次出现。

## 形变隐藏与应用入口

宿主可见性与业务可见性不再只驱动透明度。隐藏在当前胶囊的屏幕中心收拢，末段透明退场；恢复沿同一几何路径返回。可见性变换作用于展示帧，保留未变换的逻辑帧，避免反复隐藏或中途打断后累积位置误差。

首次应用入口的 `p()` 阶段尚未绑定 CapsuleView，原来的预留逻辑依赖该视图，导致随后布局先显示完整胶囊。现在先按持久 CapsuleContainer 预留入口，并在首个有效布局接管绘制，再由原生场景启动统一形变。已有胶囊的服务切换继续继承当前表面。

核对当前固件的 `e/f/h` 入口图后，未发现独立 App 窗口形变片段；其中状态栏通知和条件超时不作为统一动画的时长。用户保存的动画时长继续生效。

## 圆角与原生内容

胶囊圆角范围从 0–48 dp 扩为 0–128 dp，设置页、系统设置入口、导入导出和 Hook 配置同步更新。实际圆角以当前短边一半为上限，胶囊采用宿主原生 ROUND 曲线，使上限呈现半圆端头；展开卡片保留 G2。背景、描边、裁剪和模糊材质保持一致，胶囊高度变化后重新计算饱和半径，关闭自定义恢复原值。

原绘制路径只提取当前 CapsuleView 的单个内容，遗漏横向切换中的另一侧内容和原生月牙；内容切换还会取消同一原生根节点上的手势。修复后绘制保留原生容器的内容、变换、透明度和月牙，内容身份改变时保留同一根节点的手势序列。

原生入口和隐藏片段同时修改 CapsuleView 及其内容的缩放、位移与透明度。统一表面在这两种场景中接管当前胶囊的全局运动，避免原生运动与统一形变叠加；该接管保留到两条时间线都完成。普通内容更新和横向滑动继续保留原生变换。月牙在胶囊外侧，由外层容器绘制，避免被胶囊轮廓裁掉。

## 后续实机反馈修正

首轮回归未覆盖原生迷你胶囊的自身背景、事件指定的待进入服务，以及只改变 Drawable 宽度的场景；用户随后反馈圆角、隐藏位置、滑动外形和二次服务入口仍有问题，本轮据此补齐真实固件边界。

- 迷你胶囊 XML 自带固定 20dp / G2 背景，整树绘制会把这个旧轮廓带回统一表面。迷你容器现在只绘制原生内容子节点；独立背景副本铺满轮廓，移除图层内部的旧边距和固定尺寸。原生 `seedling.util.d` 没有 ConstantState，按其实际颜色字段和构造函数独立复制，避免复制失败时失去表面。
- 原隐藏公式无依据地上移胶囊高度的 60%，并用平方根控制高度，产生末端速度奇异。现在保持当前中心，时间曲线只应用一次，中途反向继承速度。场景隐藏接手当前展示矩形、几何速度和透明度，避免再叠加宿主隐藏形变；几何速度包括可见性变换的导数，交接不会把已经收缩的轮廓突然刹停。圆角按展示矩形更新，隐藏期间不再采样原生按压缩放。
- 原生 e/m 场景在准备阶段保留旧 `container.l`，新的服务身份由事件模型指定。统一动画读取事件中的真实目标，保持当前胶囊并向新服务的测量尺寸过渡。A/P 宽度动画可能只修改 Drawable 边界，目标改读动画段的最终宽度；不把压缩中的瞬时 Drawable 宽度误当成终点。
- 新视图先测量、后布局时按有效父容器中心定位；原生结束后仍保留尚未确认的目标，避免迟到的旧 key 或旧布局把尺寸拉回。真正的新选择和新测量会解除旧目标。业务隐藏中途进入新服务时从当前展示状态接手，真实控制中心隐藏仍然有效。
- 退场、控制中心关闭、新服务进入连续发生时，以实际展示状态重新建立可见性动画起点，保留宿主的关闭目标，并扣除新可见性动画的初始速度以免重复叠加。已隐藏的胶囊不因新服务重现；控制中心恢复时，透明度限制也连续解除。
- 背景源临时缺失时保留已有原生背景；首次没有来源才取宿主已有胶囊背景。该项为防御性连续性保障，当前 APK 中未发现主动清空 CapsuleView 背景的路径。

展开卡片按宿主当前 `getCardViews()` 的对象身份和原生顺序同步。删除首卡、中间卡片、重新排序及视图复用时重新绑定真实内容、提升存活首卡并清理旧层，避免继续显示已删除或被复用的内容。

本次与“修复流体云回收后触摸阻断”聊天合并输入修复：点按外部触发收起或进入关闭场景时，立即清空统一窗口及所有卡片层的触摸区域，让后续点击交给下层应用。透明的宿主卡片窗口仍保持禁触摸租约，直到宿主真正隐藏；视觉回到胶囊终点便恢复胶囊点击，不等待较晚的原生结束回调。反转展开立即重新接管交互。
