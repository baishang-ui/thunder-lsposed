# 流体云重构与交互验证（2026-10-22）

## 参考与适用范围

参考 Apple 官方 [Live Activities HIG](https://developer.apple.com/design/human-interface-guidelines/live-activities)、[Design dynamic Live Activities](https://developer.apple.com/videos/play/wwdc2023/10194/) 的 Dynamic Island 章节，以及 [Animate with springs](https://developer.apple.com/videos/play/wwdc2023/10158/)。本轮通过官方网页播放器查看示例，核对紧凑态、展开态、位置连续、内容替换与可打断弹簧。HIG 强调保持两种形态的元素相对位置、避免过渡内容碰撞、按内容决定尺寸。

Apple 未公开这些系统动画的全部数值参数。以下是面向 Android 宿主的对应实现与调参，不是从 iOS 提取的动画，也不宣称逐像素或所有应用模板一致。保留用户现有的材质、尺寸、时长、曲线、回弹设置与宿主业务手势。特别是宿主的多张展开卡片、月牙附件、点击展开行为与 iOS 本身不同。

修改位于宿主 Hook 和绘制桥接，不涉及独立 App UI 组件替换。

## 实现

- **统一轮廓物理**：`CloudMotion` 的位置、尺寸与圆角共用解析弹簧；取消首轮分轴生长、按剩余距离临时放大刚度的逻辑。中途切换继承当前位置和速度；迟到布局重新定向时给予完整的设置时长，避免最后几十毫秒追赶目标造成抽搐。末段用 C2 连续包络收敛，最大回弹档的零初速首个超调约为行程的 3.8%。入口的原生扩宽事件不会因重新布局而重播。
- **卡片与胶囊圆角**：以前在形态进度 `.001` 处切换 ROUND/G2 类型；现在始终使用同一原生 G2 路径族，平滑权重随形态连续从 0 到 3 再返回。轮廓、背景填充、前景边缘与原生渐变复制层使用相同的半径和权重。使用手机原生 OplusPathAdapter 比较过零权重与圆形端点的像素区域差异。
- **双向内容切换**：`CloudContentSwitch` 保留正在退出的真实 View，交叉淡入淡出并继承中断时的速度。手势方向在转发给原生根节点之前记录；新内容来自手势反方向，距离 12dp。文字时长为设置时长的 65%，限制在 120–320ms。完成时释放退出 View 的引用。
- **去除固定右移**：不再读取原生宽度动画正在改变的内容根布局偏移，将实时内容根的尺寸居中到当前胶囊内容坐标；不叠加原生包装层的 alpha、矩阵。隐藏时同样保持独立内容所有权，避免突然交还原生动画。原有文字组件的本地字符变化仍保留。
- **月牙跟随轮廓**：继续画宿主 ImageView 的月牙图案，位置由当前已显示的左右边缘加原生 2dp 间隔计算，垂直居中；不再采样另一条原生宽度动画的矩阵和 alpha。可见性变化使用独立、可打断的 180ms 临界阻尼淡入淡出。绘制、触摸区域及月牙无障碍边界共用同一放置函数。
- **控制中心显示限制**：真机复现了“卡片展开后下拉控制中心，收起回调会重新露出胶囊”。监听宿主 `NotificationShadeWindowControllerImpl.onShadeOrQsExpanded(Boolean)` 的通知栏/控制中心合并状态，作为原生显示标记之外的限制。迟到的 `w(true)` 或业务显示通知不能越过它；面板收回也不能覆盖其他原生隐藏原因。

## 性能处理与校验

同一进度共享六个通道的位置、速度和加速度采样，缓存不可变 Frame；不使用逐帧积分。稳定不透明内容直接绘制，不建立组透明度离屏层；只有交叉淡入淡出时使用组 alpha。月牙保持原生图案，不生成截图或逐帧位图。退出图层与动画在完成、切换或销毁时释放。

本轮新包已通过以下检查：

- 完整主机 Hook 校验：2,972 项统一对象生命周期检查、42,349 项轨迹检查、413 项可打断内容切换检查、59 项原生装饰复制/连续圆角检查，以及多卡片和输入所有权检查。
- 40 项独立文字渲染检查；125 项 JUnit，失败与错误均为 0。
- Debug 与 Release 离线构建、Release lint、签名验证。
- 临时自目标 Instrumentation 在真实 Android 进程执行 37 项 View/Canvas 像素检查，包括原生布局偏移不能引入第二次文字横移、月牙始终贴当前宽度边缘、忽略冲突的月牙原生矩阵，以及零权重 G2 的圆形端点。测试不启动前台 Activity，临时包执行后卸载。

Gradle 的常驻文件监视曾返回过期的 UP-TO-DATE。本轮改用 `--no-watch-fs` 重新构建，检查编译类中存在新的面板显示限制方法，再签名安装；不能仅依赖缓存命中判断源码已进入 APK。

## 复现

```sh
python3 scripts/check_effects.py
python3 scripts/check_cloud_text_renderer.py
./gradlew --no-watch-fs --offline :app:assembleDebug :app:assembleRelease :app:testDebugUnitTest
python3 scripts/check_cloud_motion_device.py --root-probe-install
```

需要设置项目可用的 JDK 17。最后一条只适用于已授权的 root 测试设备，会安装并卸载临时检查包。真实交互录制及局部画面位于 `.local/cloud-overhaul-20261022/`；原始画面只供本地分析，交付录制应使用桌面场景的顶部裁剪。
