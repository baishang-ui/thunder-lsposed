# 手势条外观

入口为“调节 → 手势条”。“修改手势条外观”默认关闭；与“隐藏手势条”和“取消底部抬高”分别保存。隐藏优先，关闭隐藏后恢复之前保存的外观。

## 尺寸和材质

- 长度：40–320 dp。
- 粗细：1–16 dp。
- 距底部高度：0–32 dp，指横条下边缘距导航视图底边的距离。实际值限制在原生导航窗口内，避免横条被裁掉；不会增大导航窗口或应用底部占位。
- “手势条材质”统一包含模糊、混色、亮暗颜色、自动换色和圆角设置，使用独立的 `Area` 参数：0–200 px 模糊、ARGB 普通 alpha 混色、0–64 dp 圆角。圆角限制到横条短边一半，未开启自定义圆角时为胶囊。

手势条使用导航窗口的 `BackgroundBlurDrawable` 在横条边界内模糊下层，再绘制一次混色。只模糊背景，不模糊横条轮廓。软件绘制或模糊接口不可用时保留混色。仅开启模糊而没有指定混色时，使用原手势条颜色的约 1/3 不透明度作为遮罩，让模糊可见；指定混色后使用设置的透明度。

## 亮暗颜色

在“手势条材质”内开启“自定义亮暗颜色”后，可分别选择深色背景上的亮色横条、浅色背景上的暗色横条。选择的颜色替换材质混色的 RGB；如果材质开启混色，最终不透明度为所选颜色不透明度 × 材质混色不透明度。不自定义颜色时沿用材质颜色；材质未指定颜色时沿用原生画笔颜色。

“根据背景自动换色”使用系统导航栏背景采样输出的 `setDarkIntensity(float)`，0 对应亮色横条，1 对应暗色横条，中间强度逐通道插值。它根据系统对应用背景的明暗判断选择两种颜色，不提取屏幕的任意 RGB 主色。Oplus 在模块首次绘制前已有强度时，从 `mLastIntensity` 读取；AOSP 首帧从原生画笔估计，后续跟随强度回调。关闭自动换色后，按系统浅色 / 深色模式选择两种颜色。

采样是否启用以及锁屏、分屏、全屏应用等特殊场景的明暗强度由系统决定。模块不读取截图，也不在绘制回调中进行磁盘、Binder 或壁纸取色操作。

## C17 接口与恢复

本地导出的 C17 `SystemUI.apk` 已核对以下实现，固件不随仓库发布：

- `NavigationHandle.onDraw` 和 `setDarkIntensity`：AOSP 横条、原生长按扩张 / 收缩参数和颜色过渡。
- `OplusNavigationHandle.onDraw`：使用 `mHeight`、`mHandleBottom` 与 `longPressAnimProgress` 绘制；`setDarkIntensity` 保存 `mLastIntensity`，原生动画继续更新自己的画笔。模块使用独立画笔，不覆写原生颜色或动画字段；保留 View 级缩放、平移、透明度及长按增加的厚度。
- `QuickswitchOrientedNavHandle.computeHomeHandleBounds`：快速切换时依据 `mDeltaRotation` 使用对应边缘、纵向长度与原生中心，保持旋转覆盖视图的窗口布局。

普通横条仅调整指示器视图宽度，保留导航输入窗口。系统旋转期间重新设置原生宽度时记录新值；关闭外观、开启隐藏或关闭模块后恢复最近的原生宽度。背景模糊在材质切换、隐藏、关闭和视图移除时清零；模糊分配失败时每次配置或重新挂载最多重试一次。

配置格式升级至 v18，支持 v3–v17 迁移；旧配置保留隐藏与底部占位设置，新增外观默认关闭。Provider 回退读取和 API 102 配置同步均携带完整外观参数。早期 v18 导出中的材质来源字段导入时丢弃，仅保留手势条自己的材质参数。

## 验证

`GestureBarSettingsTest` 覆盖持久化往返、独立材质保存、旧版迁移及早期 v18 来源字段清理、字段类型与范围。`scripts/check_effects.py --only GestureBarCheck` 执行实际 Java 处理器，覆盖尺寸换算、与通知条 / 磁贴材质隔离、亮暗切换与插值、横屏快速切换、模糊缓存与失败回退、重新挂载、隐藏 / 关闭恢复、导航占位和输入区域保护及 Provider 配置回退。

这些检查使用 Android / Oplus 替身验证处理器行为；最终背景模糊、系统采样覆盖、长按动画与显示效果仍需安装到 C17 设备后确认。
