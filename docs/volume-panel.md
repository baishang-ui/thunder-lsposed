# 音量面板

入口：**调节 → 音量 → 音量面板**。适配本地采集的 ColorOS 17 SystemUI。安装更新后需重启系统界面加载新的 Hook，之后参数自动保存并实时同步。

## 参数

| 区域 | 参数 |
| --- | --- |
| 侧边音量条 | 宽度 32–96 dp、长度 120–400 dp；圆角 0–64 dp、背景混色、模糊半径 0–200 px |
| 原生按钮 | 展开、应用音量、字幕和面板设置按钮大小 36–72 dp；独立圆角、混色和模糊 |
| 展开面板 | 保留原生动画的紧凑展开；独立圆角、混色和模糊 |

各项自定义默认关闭。混色使用所选颜色及其不透明度，音量进度保留系统配色。音量配置字段继续兼容原有导出格式。

## 原生展开与收起

“跟随音量条展开”保留 `OplusVolumeDialogImpl.expandPanel()` 和 `OplusVolumeDialogView.expandPanel()` 的完整执行。系统自行更新展开标志、控制器状态、音量行数据源和 `PanelTransitionSession`，继续运行 `VolumeItemAnimator`、原生按钮动画与面板背景动画。

Hook 调整以下几何输入：

- 在展开前记录当前侧边音量行容器的位置。音量行仍使用原生弹簧插值、时长、错峰次序、透明度、按压变形和中断收起逻辑，只调整展开终点与收起锚点。
- 小面板包住原音量条的位置，并向屏幕内侧展开；按原生目标音量行数量计算宽度，使用可见窗口与原生根布局的交集避让屏幕边缘。左右侧均保留原来的物理排列顺序。
- 标题、提示、设置图标与设置文字使用原生视图，仅修改约束位置。原生系统音量、应用音量、无障碍、勿扰、安全音量及声音设置入口继续由系统处理。
- 面板背景保留系统 Drawable。包装层只改变其实际绘制边界与裁剪；原生模糊量和透明度动画继续驱动同一个 Drawable。设置后端实际边界，避免只裁剪画布却仍提交全屏模糊。
- 保留原生全屏透明窗口、RecyclerView 层级与坐标系，让音量行能从侧边连续运动到面板内。屏幕上只绘制紧凑卡片；外部点击调用系统的收起流程，内部拖动仍走系统触摸分发。运动中的音量行和原生提示区域也允许交互。
- 原生动画完成并进入终止隐藏状态后恢复标题、按钮约束和背景。配置或方向改变时通过原生关闭流程收起，避免在动画中途拆掉面板。关闭功能后使用系统展开方式。

较宽的自定义音量条在展开面板中会按可用宽度收窄，避免多路音量互相覆盖。横屏垂直空间不足时缩短原生音量行视口。侧边音量条仍使用设置中的尺寸。

## 音量条与材质细节

音量条宽度同时作用于原生背景、进度和测量最小宽度，保留当前值与静止值之间的按压变形比例。只有参数发生变化时才刷新派生几何，并保留动画当前姿态；普通测量和状态更新不会反复重置按压动画。

长度通过原生 RecyclerView 视口调整，保留测得的标签、留白和溢出开销。音量行与滑条容器的高度、负顶部边距继续由原生侧边进度溢出和面板交接逻辑管理。

圆角修改背景和进度的原生基础几何，同时调整相应的垂直留白，避免圆角变化导致音量条端点漂移。原生材质宿主继续产生平滑路径、按压轮廓与高光；模糊提交使用宿主自身的密度和当前动画半径，保留其形状提供器。背景混色通过原生材质管线提交一次，原生进度色不变。

音量条、按钮、面板分别标记自己的原生模糊配置，与控制中心和通知材质独立。非模糊背景保留原始 Drawable，自定义关闭后恢复原始绘制。设置关闭时恢复保存的布局、基础宽度、半径和留白。

## 验证范围

- `VolumeSettingsTest`：配置兼容与边界、左右锚点、横屏及窄窗口限位、物理坐标与动画位移换算。
- `python3 scripts/check_effects.py --only VolumePanelCheck`：执行实际 Hook 回调，检查原生展开不被取消、原生对象与数据源保留、动画终点、背景实际边界、按压比例、材质密度与圆角、触摸分发和终止恢复。
- `python3 scripts/check_volume_native.py /path/to/SystemUI.apk`：使用 androguard 检查采集固件中的反射目标，并确认原生音量行动画仍调用所接入的几何方法和原生时长解析器。

这些检查验证代码行为和固件符号，不证明真机视觉表现。仍需在目标固件检查展开/收起的连续性、动画中再次按音量键或点击外部、横竖屏、应用音量行更新、锁屏、拖动与安全音量提示，以及模糊后端的实际边界。
