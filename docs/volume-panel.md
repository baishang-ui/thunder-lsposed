# 音量面板

入口：**调节 → 音量 → 音量面板**。适配本地采集的 ColorOS 17 SystemUI 音量实现。首次安装此功能后需重启系统界面加载 Hook，之后设置自动保存并实时同步。

## 可调参数

| 区域 | 参数 |
| --- | --- |
| 侧边音量条 | 宽度 32–96 dp、长度 120–400 dp；背景圆角 0–64 dp、混色、模糊半径 0–200 px |
| 按钮 | 侧边按钮大小 36–72 dp；独立圆角、混色和模糊 |
| 展开面板 | 独立圆角、混色、模糊；可切换为跟随音量条展开的小面板 |

各项自定义默认关闭。混色使用所选颜色及其不透明度，0% 不叠色、100% 为所选纯色；模糊半径与混色独立。音量进度仍保留系统颜色。配置格式为 v13，v3–v12 导入时新增音量选项跟随系统。

## 跟随音量条展开

开启“跟随音量条展开”后，在 `OplusVolumeDialogImpl.expandPanel()` 进入原生全屏状态之前接管展开。使用当前活动音量条的屏幕坐标，在空间较宽的一侧显示约 300 dp 宽的小面板，并限制在可用屏幕内。高度超过可用空间时，内容可滚动。窗口不添加全屏遮罩；支持点击外部、返回键、收起按钮及原生超时关闭。

面板从当前原生音量行读取可用音频流、音量上下限和禁用状态，使用原生 `VolumeDialogController.setActiveStream/setStreamVolume` 调节，继续由系统处理音量权限、勿扰限制和安全音量。外部音量变化会同步到小面板；同步 UI 不会反向写入音量。触摸期间延长原生超时。声音设置按钮沿用原生按钮点击处理；应用单独音量与字幕仍由原生侧边按钮处理。

配置变更、旋转、主题变化、原生窗口关闭、宿主视图脱离和销毁时，小面板释放并移除位置监听。关闭功能后，下次展开使用原生面板。

## 材质与恢复

- 通过 `VolumeBlurManager` 的音量条、按钮、侧边附件及面板背景工厂，标记各自的原生模糊代理，复用项目已有的单次混色算法。音量条、按钮、面板、控制中心和通知的参数相互独立。
- 条长宽同时调整布局、背景宽度、进度宽度、最小宽度和最大高度，使显示与原生触摸映射一致；关闭尺寸调节时恢复保存的布局及内部几何值。
- 音量条绘制期间临时覆盖填色及背景/进度圆角，结束后恢复，失败路径也恢复；原生材质宿主的圆角解析使用相同半径。
- 无原生 AutoBlurDrawable 的填色回退保留原始 Drawable。根据当前配置绘制自定义颜色或裁剪，关闭后直接绘制原始背景。
- 小面板及其操作按钮通过窗口根节点的 `BackgroundBlurDrawable` 获取背景模糊，再叠加一次所选颜色；不模糊文字和操作控件。设备未提供此后端时保留颜色与圆角，并在运行报告记录模糊失败。

## 验证

`VolumeSettingsTest` 覆盖配置往返、旧版迁移、非法参数和运行时限幅；几何测试覆盖左右位置、靠底部、横屏及窄窗口。

`python3 scripts/check_effects.py --only VolumePanelCheck` 用 Android / C17 替身执行实际 Hook，覆盖全屏状态接管、系统音量控制器调用、状态同步、禁用状态、拖动超时、旋转清理、原生材质接入、失败后的绘制状态恢复、尺寸恢复及无模糊背景恢复。完整效果回归同时检查其他现有区域。

这些检查不替代真机验证。当前未连接设备，仍需在目标固件确认触摸手感、原生安全音量提示、锁屏显示、模糊效果和动画期间的锚点位置。

建议真机依次检查：左右侧音量条展开、顶部/底部避让、横竖屏切换、长按拖动与实体音量键同步、勿扰和安全音量、声音设置入口、关闭各项自定义及模块总开关后的恢复。运行报告中的 `volume-*` 记录接入与材质命中。
