# 音量面板

入口：**调节 → 音量 → 音量面板**。适配本地采集的 ColorOS 17 SystemUI。安装更新后需正常重启手机加载新的 Hook，之后参数自动保存并实时同步。

## 参数

| 区域 | 参数 |
| --- | --- |
| 侧边音量条 | 宽度 32–96 dp、长度 80–400 dp；圆角 0–64 dp、背景混色、模糊半径 0–200 px |
| 原生按钮 | 侧边展开、应用音量、字幕及面板下方快捷按钮为正方形，边长跟随音量条宽度；共用音量条的圆角、混色和模糊 |
| 展开面板 | 保留原生动画的紧凑展开；独立圆角、混色和模糊 |

各项自定义默认关闭。混色使用所选颜色及其不透明度，音量进度保留系统配色。配置导出格式为 v20，兼容导入旧版配置；v13/v14 的按钮独立参数会被音量条参数取代。

侧边尺寸与圆角在原生布局完成后同步，覆盖首次测量尚未完成、`updateRowsH` 异步更新和延迟重绑时的尺寸覆盖。原生全屏展开与紧凑展开期间沿用各自的几何处理；返回侧边后重新应用配置。音量条圆角变化后重新提交缓存材质，原生按钮实际尺寸变化后再按新边界更新材质圆角。重复布局不重置按压动画，也不重复提交尺寸未变的材质；面板重建、窗口脱离与销毁时清理对应布局观察器。

`python scripts/check_effects.py --only VolumePanelCheck VolumeLiquidEntranceCheck ShortcutPerformanceCheck` 覆盖延迟测量、原生重绑、圆角材质刷新、窗口重建与重新附着、关闭自定义及原生动画状态保留。这些检查使用合成运行时，实际显示效果仍需目标设备验证。

## 侧边音量条液态入场

“iOS 液态入场”只修改按音量键后原始侧边音量条的入场。使用设置页现有的 MIUIx 设置项与官方 LiquidToggle 开关，默认关闭；v19 及更早配置导入时默认保持系统入场。

开启后，原始音量条从屏幕边缘拉出，与边缘的第二个形状先融合、拉细中间的连接，再分离，最后弹性停稳。两侧轮廓直接复用固件通知左滑 `NotificationMenuRowMetaBallController` 使用的 `MetaBallBlurDrawable` 及互相引用的两个 MetaBall，复制当前音量条原生材质与模糊捕获；不新建液态 Shader。原生 `doShowOrHideAnimate` 与 `VolumeAnimUtil.startViewPropertyAnimation` 继续管理位移、完成通知及帧率提升，780 ms 时长，使用 COUI 弹簧（response 0.82、bounce 0.58）。条身及按钮的起始横纵缩放均为 1，不再压窄、拉高整个控件。保留原有快速位移：约 200 ms 到达静止位置附近，约 350 ms 达到约 29% 的超调，然后弹性停稳。融合距离跟随位移，不放慢入场；条身突出部分的形变回收使用单独的平滑包络。系统关闭动画或降级复杂动画时保留原生路径。

将条身内侧边缘置于屏幕内约自身宽度的 18%，其余部分与屏幕外锚点相交；第一帧就从边框中显现。连接距离跟随原生位移；达到释放位置后，实际形变量以独立的 220 ms 包络回收。两侧主体尺寸保持不变，中间的原生连接变形。右侧（或左侧）锚点的完整轮廓都位于物理屏幕边缘之外，屏幕内只出现融合形变，不额外显示分离后的边缘液滴。主音量条尚未进入屏幕时不绘制连接，避免锚点抢先出现。锚点宽度取条身宽度的 1.35 倍（上限 72 个物理屏幕 dp），高度取条身宽度的 2.3 倍（不超过条身高度），将连接集中在条身中部，避免等高双柱形成大片薄膜。捕获范围固定为 96 dp，锚点使用自身宽高的半短边作为圆角。第二份原生材质提前准备；两份模糊捕获区域在形变过程中保持固定，直接批量更新原生 MetaBall 参数，每份材质每帧只同步一次 Shader，避免逐个位置、大小更新各自提交，以及每帧改变 blendRange 导致捕获边界反复变化。

捕获范围与融合强度分别计算。两侧球的横向连接变形范围（`shapeRangeFactorX`，沿连接垂直方向）保持 1.6，不再压到零，避免出现细长针状连接后突然消失。根据实际间距和额外融合距离计算原生 `blendShape`；额外距离取条身宽度的 0.85 倍，上限 48 个物理屏幕 dp，让中部连接在快速拉出时保持清晰可见。总强度以静止间距、初始位移和上述额外距离计算的上限约束，避免异常位姿无限拉伸。

条身拉出进度达到 0.85 后，开始约 220 ms 的形变回收，跟随系统动画时长倍率。固件的 `blendShape` 同时影响形变量和距离门控，因此不能通过直接降低它来回收条身凸起：跨过 5 px 距离阈值会使凸起整体消失。回收期间保持原生融合支撑距离和变形范围，使用原生 `MetaBallParamsKt.buildMetaBallUniformArrays` 的结果，仅对当前音量条与临时边缘材质的 pair 1/2 参数施加五次曲线包络：`preCmpArray12[11]`、`[14]` 为两侧实际位移形变量，`[17]` 为平滑并集强度。两份互相引用的材质使用相同包络，使音量条一侧的凸起分开后仍逐帧缩回原轮廓。球的宽高、圆角、透明度、支撑宽度及其他材质参数不变，不编写或替换 Shader。

参数对象通过当前入场的弱引用标记限定范围，通知和流体云等其他材质不受影响。对原生 uniform 构建调用链取消内联优化，保证真实渲染路径进入 Hook。完整提交形变量为零的一帧后，下一帧才释放临时捕获和参数标记；中断、关闭开关或原生结束回调也会清理。回收包络不会随弹簧回弹倒放。

两份材质均显式调用原生 `setEnableBlurShader(true)`，与系统通知侧滑菜单一致；仅创建 MetaBall 后端不会保证它离开普通位图绘制路径。开启液态入场期间，条身在入场、分离及静止时始终使用相同原生材质路径和捕获扩展范围，分离恢复主球原有的连接范围和强度、移除连接、注销临时材质捕获，不在动画末尾切换 Shader 开关或把 blendRange 清零，防止颜色突变。关闭此功能时恢复各条身原有的开关与捕获范围；弱引用登记不延长原生材质的生命周期。首帧提前转发原生 Drawable 边界，确保系统主液滴已创建后才更新形状参数。

原生 Shader 会把当前主液滴重新居中，其他液滴坐标相对主液滴计算。因此边缘材质绘制时还需平移到边缘锚点，不能只修改主液滴的 `posX`；否则第二份材质会画在条身中央并向内侧变形。绘制后立即恢复 Canvas，主音量条不继承这个平移。

接入只匹配 `volume-bar` 背景材质；同一 `OplusVolumeSeekBar` 上的音量进度填充也有独立模糊代理，不能仅凭宿主 View 匹配。进度层沿用系统自己的绘制，不得把它的后续 draw 当作背景替换而提前释放连接。

边缘锚点通过逆变换固定到当前窗口的实际屏幕边缘，镜像支持左右侧；连接形变随原生位移在后半程逐步退回两端并分离，分离后回弹不会重新吸附。绘制前监听器仅在连接期间刷新材质，避免 RenderNode 属性动画不重新录制内容；结束后移除。连接期间临时释放祖先裁剪。原生按压裁剪会截断液态连接，因此整个入场期间以 `OplusVolumeBarMaterialHost.resolveVisualShapeInto` 给出的实际可见形状作为原生背景边界，绘制后恢复原 Drawable 边界，避免误用带留白的 View 矩形、背景伸进下方按钮或分离后突然切回另一套轮廓。保留音量行底部和按钮顶部的原生缩放中心，整个过程不修改枢轴或结束时补偿位移。多条音量行共享裁剪引用计数；正常结束、快速收起、展开、脱离窗口、配置变化与方向变化时释放临时捕获和连接形状，恢复原生裁剪。

`python scripts/check_effects.py --only VolumePanelCheck VolumeLiquidEntranceCheck` 检查入场门控、左右边缘、弹簧委托、条身实际 uniform 形变量逐帧回收、材质范围隔离及 0.5/1/2 倍系统动画时长、原生结束通知及中断清理，属于合成运行时验证；GPU 连接轮廓、真实帧率和手感仍需目标设备验证。

## 原生展开与收起

“跟随音量条展开”保留 `OplusVolumeDialogImpl.expandPanel()` 和 `OplusVolumeDialogView.expandPanel()` 的完整执行。系统自行更新展开标志、控制器状态、音量行数据源和 `PanelTransitionSession`，继续运行 `VolumeItemAnimator`、原生按钮动画与面板背景动画。

Hook 调整以下几何输入：

- 紧凑展开不执行全屏面板专用的 `PanelExpandPreludeAnimator` 按钮缩小退场，也不叠加 `startBtnThickAnim` 的向上收缩。侧边按钮组读取原主音量条的实际屏幕横向位移，并抵消系统对按钮父容器的重新布局，保留接入瞬间的屏幕纵向位置和按压姿态；即使进度暂时不变，也继续校正布局偏移。主音量行立即移动，新增音量行保留原生弹簧、错峰和完成监听器，在原错峰上延后 99 ms 进入。快捷区在主音量行位移经过 35% 后启动独立的原生 COUI 弹簧（response 0.48、bounce 0）：实际声音组件宽度从单个圆形连续展开为三段式胶囊，原按钮组随形变同步淡出；底座展宽后再渐入原生图标与选中块，避免三个图标挤在初始圆形内。主音量行到达终点后形变仍可平滑收尾；反向与中断收起重定向同一个弹簧，不另起上移退场。
- 在展开前记录当前侧边音量行容器的位置。音量行仍使用原生弹簧插值、时长、错峰次序、透明度、按压变形和中断收起逻辑，只调整展开终点与收起锚点。新增行共用展开前记录的固定侧边原点，保留原生横向位移、透明度与错峰；中间两列向左移至目标位置，最外侧闹钟列也从同一个原始位置向内位移并渐入，不单独从屏幕右侧移入，也不跟随主音量条的实时位置。最终整组在可用屏幕范围内向内收 16 dp，保留闹钟的短程位移和各列等距；背景边缘从原位置同步平移至最终边界，左侧音量面板镜像处理。收起沿原生位移与透明度反向返回。记录主音量条的可见顶部，并在启动原生动画前对齐各行纵向姿态，让展开仅沿水平方向移动，不因面板高度改变而上下漂移。绘制前按实际滑条屏幕顶部补偿原生绑定时的留白及纵向位移重置，覆盖动画启动前的布局交接帧。
- 小面板包住原音量条的位置，并向屏幕内侧展开；按原生目标音量行数量计算宽度，使用可见窗口与原生根布局的交集避让屏幕边缘。左右侧均保留原来的物理排列顺序。
- 紧凑面板显示原生音量条，以及下方单独一排声音模式与免打扰快捷按钮；隐藏“系统音量”标题、标题图标、面板说明、设置按钮与设置文字，以及音量行下方的文字标签。使用 `GONE` 移除布局与触摸占位，在绑定后和原生绘制前维持隐藏，避免原生动画或数据刷新重新显示。原生滑条的无障碍内容描述、图标点击、音量限制与安全音量处理继续保留。
- 宽度过渡读取原生音量行的实际屏幕位移进度，背景从音量条所在侧向内展宽，反向收起时经过相同的中间宽度。帧观察器只在原生绘制帧中取样，一帧内复用进度，不再递归刷新整棵音量行视图；仅在屏幕限位需要改变条宽时额外刷新滑条。起止宽度与圆角相同时跳过临时姿态分配和反射写入，快捷图标只在状态或自身动画变化时更新。音量行不新建计时器或替换原生动画监听器；底部形变单独复用原生 COUI 弹簧；音量行被替换时使用原生背景进度作为回退。
- 音量条的背景与进度在完整 `draw()` 期间插值可见宽度与圆角，包含原生材质背景绘制；不缩放图标、标签或触摸坐标。绘制后恢复原生按压动画字段，异常绘制同样恢复。
- 面板背景保留系统 Drawable。包装层只改变其实际绘制边界与裁剪；原生模糊量和透明度动画继续驱动同一个 Drawable。设置后端实际边界，避免只裁剪画布却仍提交全屏模糊。轮廓复用原生 `OplusVolumeShapePathHelper.buildClipPath` 的平滑圆角（权重 3），动画中跟随实际边界；平台／动态模糊同步提交平滑权重并使用后端局部形状接口，不传入视图坐标路径以免非零边界被重复偏移，纯色填充使用原生 `SmoothCornersGradientDrawable`，防止普通圆角填充再次裁掉平滑轮廓。配置提交结束恢复原生配置。
- 保留原生全屏透明窗口、RecyclerView 层级与坐标系，让音量行能从侧边连续运动到面板内。屏幕上只绘制紧凑卡片；外部点击调用系统的收起流程，内部拖动仍走系统触摸分发。运动中的音量行和原生提示区域也允许交互。
- 原生动画完成并进入终止隐藏状态后恢复视图原有可见性和背景。配置或方向改变时通过原生关闭流程收起，避免在动画中途拆掉面板。关闭功能后使用系统展开方式。

音量条尺寸读取展开前主音量条的实际测量长度与基础宽度，展开时所有音量条沿用这个尺寸，去掉原先的 144 dp 长度、56 dp 条宽和 320 dp 卡片宽度上限。宽度为 **列数 × 实际条宽 +（列数 + 1）× 8 dp**；列数至少为 4，以容纳响铃、振动、静音、免打扰四格快捷区，少于四条音量行时在其上方居中，不再为标题/设置文字保留宽度。条间距与四周内边距统一为 8 dp，按可见条边缘计算，扣除原生行容器两侧透明留白。

高度为 **可见主音量条高度 + 快捷按钮边长 + 三段 8 dp 间距**（上边距、条与按钮之间、下边距）。扣除原生滑条容器的透明留白与文字标签占位。只有内容触及真实屏幕边界时才统一收窄或缩短，保持原音量条的纵向位置，不把面板往上移动；侧边恢复时仍使用设置中的尺寸。

下方前三格为“响铃／振动／静音”直接点选的三段式，共用一个材质底座；第四格为免打扰，三段式底座与免打扰铺满面板内宽。免打扰对齐最右侧音量条，前三种声音模式在原生底座内部三等分，保留其选中时的图标避让位移。无振动器时禁用振动段；原生振铃限制和实体静音拨杆仍生效。免打扰按钮开关当前模式，关闭后再次点击恢复本次面板中最近的非零免打扰模式。操作调用原生 `VolumeDialogController`，选中态和无障碍描述跟随确认后的原生状态刷新；重复选择当前声音模式不重复提交。声音图标和 Lottie 动画由当前固件 `OplusQSThreeStageLayout` 提供（静态图标为 `status_bar_qs_mute_inactive`、`vibrate_on`、`status_bar_qs_mute_active`），免打扰使用 `OplusDndTile` 的 `status_bar_qs_dnd_active/inactive` 月亮图标。快捷区高度、底座圆角、混色与模糊共用音量条参数，两个选中块均使用音量条的 BAR_PROGRESS 材质与共享圆角，三段式和免打扰底座均通过原生音量条 `BAR_BACKGROUND` 材质工厂创建，并同步接收 `applyBarPanelBottomProgress` 的材质进度；展开、反向收起和归零均保持与音量条相同的混色阶段，重复进度不重复提交。

快捷区进出场读取原音量行动画进度，反向收起时同步回退。原生三段式宿主的实际宽度从一个按钮边长增加到最终三段式宽度，从移动主音量条的位置过渡到最终位置；背景材质同步变化成胶囊，不再以裁剪窗口揭开完整控件。每次布局尺寸变化后调用原生 `setTranslationXAndScale` 更新图标及选中块位置。声音模式直接实例化当前固件控制中心的 `OplusQSThreeStageLayout`，保留其 COUI 弹簧位移、拖动切换和 Lottie 图标动画，背景及选中块替换为音量条原生材质，移除应用自绘细边框和 200 ms 仿制声音切换动画。仅调整宿主布局和图标尺寸：选中块铺满一格按钮高度、图标沿用原生 20 dp，条宽较小时等比限制以容纳原生放大反馈。三段式内部保持原生三等分布局，免打扰保持单独一格。两者的选中底色使用同一原生 `getVolumeBarProgressDrawable`；纯色后端复用原生平滑圆角和音量条进度色。免打扰使用原生 `OplusQSIconView`，提交 `dnd` 状态、`qs_dnd_lottie` 前缀和原生动画策略 17，复用开关 Lottie；图标对比色在提交原生动画前设置，避免动画捕获上一状态颜色而出现白底白图；底色使用 COUI 弹簧透明度过渡，按压由展开音量条的原生触摸高光驱动。切换中再次点击时重定向现有弹簧，原生图标代理负责反向图标动画；不再叠加两张静态图标的手写交叉淡入。

声音模式的初始状态与外部更新通过原生 `setSelectedIndex(ringerMode, description)` 传入；点击和拖动均读取原生控件提交的模式标签，再调用音量控制器。原生控件的预选结果会重新对齐控制器状态，避免无振动器、实体拨杆、振铃限制或异步回执导致假选中。未展开完成或振铃不可操作时，通过原生编辑模式与子项禁用共同禁止交互。原生结束隐藏后取消指示器、图标位移／缩放／颜色、按压弹簧与 Lottie 动画，清理待执行的长按任务、快捷区和监听器；同时取消底部形变弹簧；不改变音量行的原生弹簧与时序。

三段式和免打扰统一使用 `COUISpotLightEffectDrawable` 与 `VolumeSpotLightTarget.SEEK_BAR_PANEL`，由固件处理按下、移动、松开和取消的高光动画；轮廓使用音量条的 `OplusVolumeShapePathHelper` 与共享圆角。展开音量条启用 `mEnableCustomEnlarge`，且展开态不会调用侧边单条的整体缩放，因此快捷按钮同样不叠加通用按钮缩小动画。仅屏蔽音量面板这组实例的 QS 按压缩放，控制中心实例保持原样。禁用、脱离窗口和面板收起时取消高光并释放回调。

面板关闭时，原侧边按钮及快捷区同步读取原主音量条及父容器的透明度。关闭期间已淡出的部分保持淡出，避免原生移除动画在结束时把行透明度重置为 1，导致原按钮在最终隐藏前闪回或残留。

## 音量条与材质细节

音量条宽度同时作用于原生背景、进度和测量最小宽度，保留当前值与静止值之间的按压变形比例。只有参数发生变化时才刷新派生几何，并保留动画当前姿态；普通测量和状态更新不会反复重置按压动画。

长度通过原生 RecyclerView 视口调整，保留测得的标签、留白和溢出开销。音量行与滑条容器的高度、负顶部边距继续由原生侧边进度溢出和面板交接逻辑管理。

圆角修改背景和进度的原生基础几何，同时调整相应的垂直留白，避免圆角变化导致音量条端点漂移。原生材质宿主继续产生平滑路径、按压轮廓与高光；模糊提交使用宿主自身的密度和当前动画半径，保留其形状提供器。背景混色通过原生材质管线提交一次，原生进度色不变。展开快捷按钮在首次布局前读取已设置的布局尺寸计算圆角，挂载或尺寸改变后重新提交原生材质与形状，避免零尺寸把圆角缓存为 0。两个快捷底座的触摸高光和选中进度层沿用音量条圆角；纯色背景仅修改圆角时同步调整原始形状，绘制后还原，保证圆角减小至 0 也生效。

原生缓存材质在动画中会绕过 `ViewBlurProxy` 直接更新颜色、高光与描边圆角。Hook 同时覆盖这些缓存提交入口，并在提交后恢复原始配置，避免原生动画覆盖自定义混色和圆角；异常路径同样还原。

音量条与按钮的原生模糊配置共用一组参数；面板背景保留单独参数。它们与控制中心和通知材质独立。非模糊背景保留原始 Drawable，自定义关闭后恢复原始绘制。设置关闭时恢复保存的布局、基础宽度、半径和留白。
