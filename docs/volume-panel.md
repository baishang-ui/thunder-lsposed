# 音量面板

入口：**调节 → 音量 → 音量面板**。适配本地采集的 ColorOS 17 SystemUI。安装更新后需正常重启手机加载新的 Hook，之后参数自动保存并实时同步。

## 参数

| 区域 | 参数 |
| --- | --- |
| 侧边音量条 | 宽度 32–96 dp、长度 80–400 dp；圆角 0–64 dp、背景混色、模糊半径 0–200 px |
| 原生按钮 | 侧边展开、应用音量、字幕及面板下方快捷按钮为正方形，边长跟随音量条宽度；共用音量条的圆角、混色和模糊 |
| 展开面板 | 保留原生动画的紧凑展开；独立圆角、混色和模糊 |

各项自定义默认关闭。混色使用所选颜色及其不透明度，音量进度保留系统配色。配置导出格式为 v16，兼容导入旧版配置；v13/v14 的按钮独立参数会被音量条参数取代。

## 原生展开与收起

“跟随音量条展开”保留 `OplusVolumeDialogImpl.expandPanel()` 和 `OplusVolumeDialogView.expandPanel()` 的完整执行。系统自行更新展开标志、控制器状态、音量行数据源和 `PanelTransitionSession`，继续运行 `VolumeItemAnimator`、原生按钮动画与面板背景动画。

Hook 调整以下几何输入：

- 紧凑展开不执行全屏面板专用的 `PanelExpandPreludeAnimator` 按钮缩小退场，也不叠加 `startBtnThickAnim` 的向上收缩。侧边按钮组读取原主音量条的实际屏幕横向位移，并抵消系统对按钮父容器的重新布局，保留接入瞬间的屏幕纵向位置和按压姿态；即使进度暂时不变，也继续校正布局偏移。主音量行立即移动，新增音量行保留原生弹簧、错峰和完成监听器，在原错峰上延后 99 ms 进入。快捷区在主音量行位移经过 55% 后接入，原按钮组同步淡出；反向收起读取同一进度，不另起上移退场。
- 在展开前记录当前侧边音量行容器的位置。音量行仍使用原生弹簧插值、时长、错峰次序、透明度、按压变形和中断收起逻辑，只调整展开终点与收起锚点。新增行的起点至少在终点外侧一个列间距，原音量行继续沿用记录的侧边锚点，避免最外侧闹钟列起终点重合而只淡入淡出；原生行状态记录该起点，收起时沿同一位移反向返回。记录主音量条的可见顶部，并在启动原生动画前对齐各行纵向姿态，让展开仅沿水平方向移动，不因面板高度改变而上下漂移。
- 小面板包住原音量条的位置，并向屏幕内侧展开；按原生目标音量行数量计算宽度，使用可见窗口与原生根布局的交集避让屏幕边缘。左右侧均保留原来的物理排列顺序。
- 紧凑面板显示原生音量条，以及下方单独一排声音模式与免打扰快捷按钮；隐藏“系统音量”标题、标题图标、面板说明、设置按钮与设置文字，以及音量行下方的文字标签。使用 `GONE` 移除布局与触摸占位，在绑定后和原生绘制前维持隐藏，避免原生动画或数据刷新重新显示。原生滑条的无障碍内容描述、图标点击、音量限制与安全音量处理继续保留。
- 宽度过渡读取原生音量行的实际屏幕位移进度，背景从音量条所在侧向内展宽，反向收起时经过相同的中间宽度。帧观察器只在原生绘制帧中取样，一帧内复用进度，不再递归刷新整棵音量行视图；仅在屏幕限位需要改变条宽时额外刷新滑条。起止宽度与圆角相同时跳过临时姿态分配和反射写入，快捷图标只在状态或自身动画变化时更新。不新建计时器或替换原生动画监听器；音量行被替换时使用原生背景进度作为回退。
- 音量条的背景与进度在完整 `draw()` 期间插值可见宽度与圆角，包含原生材质背景绘制；不缩放图标、标签或触摸坐标。绘制后恢复原生按压动画字段，异常绘制同样恢复。
- 面板背景保留系统 Drawable。包装层只改变其实际绘制边界与裁剪；原生模糊量和透明度动画继续驱动同一个 Drawable。设置后端实际边界，避免只裁剪画布却仍提交全屏模糊。轮廓复用原生 `OplusVolumeShapePathHelper.buildClipPath` 的平滑圆角（权重 3），动画中跟随实际边界；平台／动态模糊同步提交平滑权重并使用后端局部形状接口，不传入视图坐标路径以免非零边界被重复偏移，纯色填充使用原生 `SmoothCornersGradientDrawable`，防止普通圆角填充再次裁掉平滑轮廓。配置提交结束恢复原生配置。
- 保留原生全屏透明窗口、RecyclerView 层级与坐标系，让音量行能从侧边连续运动到面板内。屏幕上只绘制紧凑卡片；外部点击调用系统的收起流程，内部拖动仍走系统触摸分发。运动中的音量行和原生提示区域也允许交互。
- 原生动画完成并进入终止隐藏状态后恢复视图原有可见性和背景。配置或方向改变时通过原生关闭流程收起，避免在动画中途拆掉面板。关闭功能后使用系统展开方式。

音量条尺寸读取展开前主音量条的实际测量长度与基础宽度，展开时所有音量条沿用这个尺寸，去掉原先的 144 dp 长度、56 dp 条宽和 320 dp 卡片宽度上限。宽度为 **列数 × 实际条宽 +（列数 + 1）× 8 dp**；列数至少为 4，以容纳响铃、振动、静音、免打扰四格快捷区，少于四条音量行时在其上方居中，不再为标题/设置文字保留宽度。条间距与四周内边距统一为 8 dp，按可见条边缘计算，扣除原生行容器两侧透明留白。

高度为 **可见主音量条高度 + 快捷按钮边长 + 三段 8 dp 间距**（上边距、条与按钮之间、下边距）。扣除原生滑条容器的透明留白与文字标签占位。只有内容触及真实屏幕边界时才统一收窄或缩短，保持原音量条的纵向位置，不把面板往上移动；侧边恢复时仍使用设置中的尺寸。

下方前三格为“响铃／振动／静音”直接点选的三段式，共用一个材质底座；第四格为免打扰，三段式底座与免打扰铺满面板内宽。免打扰对齐最右侧音量条，前三种声音模式在原生底座内部三等分，保留其选中时的图标避让位移。无振动器时禁用振动段；原生振铃限制和实体静音拨杆仍生效。免打扰按钮开关当前模式，关闭后再次点击恢复本次面板中最近的非零免打扰模式。操作调用原生 `VolumeDialogController`，选中态和无障碍描述跟随确认后的原生状态刷新；重复选择当前声音模式不重复提交。声音图标和 Lottie 动画由当前固件 `OplusQSThreeStageLayout` 提供（静态图标为 `status_bar_qs_mute_inactive`、`vibrate_on`、`status_bar_qs_mute_active`），免打扰使用 `OplusDndTile` 的 `status_bar_qs_dnd_active/inactive` 月亮图标。快捷区高度、底座圆角、混色与模糊共用音量条参数，内部选中块保持控制中心的原生形状，三段式和免打扰底座均通过原生音量条 `BAR_BACKGROUND` 材质工厂创建，并同步接收 `applyBarPanelBottomProgress` 的材质进度；展开、反向收起和归零均保持与音量条相同的混色阶段，重复进度不重复提交。

快捷区进出场的淡入与裁剪读取原音量行动画进度，反向收起时同步回退。声音模式直接实例化当前固件控制中心的 `OplusQSThreeStageLayout`，保留其原生填充选中块、主题配色、COUI 弹簧位移、按压反馈、拖动切换和 Lottie 图标动画，移除应用自绘细边框和 200 ms 仿制声音切换动画。仅调整宿主布局和图标尺寸：选中块沿用原生 42 dp、图标沿用原生 20 dp，条宽较小时等比限制以容纳原生放大反馈。三段式内部保持原生三等分布局，免打扰保持单独一格。两者的选中底色使用同一原生 `HighLightIconBg` 材质、`OvalOutlineProvider` 和 `TileViewFlag.Active` 状态。免打扰使用原生 `OplusQSIconView`，提交 `dnd` 状态、`qs_dnd_lottie` 前缀和原生动画策略 17，复用开关 Lottie；图标对比色在提交原生动画前设置，避免动画捕获上一状态颜色而出现白底白图；底色使用 COUI 弹簧透明度过渡，按压由 `COUIPressFeedbackHelper` 驱动。切换中再次点击时重定向现有弹簧，原生图标代理负责反向图标动画；不再叠加两张静态图标的手写交叉淡入。

声音模式的初始状态与外部更新通过原生 `setSelectedIndex(ringerMode, description)` 传入；点击和拖动均读取原生控件提交的模式标签，再调用音量控制器。原生控件的预选结果会重新对齐控制器状态，避免无振动器、实体拨杆、振铃限制或异步回执导致假选中。未展开完成或振铃不可操作时，通过原生编辑模式与子项禁用共同禁止交互。原生结束隐藏后取消指示器、图标位移／缩放／颜色、按压弹簧与 Lottie 动画，清理待执行的长按任务、快捷区和监听器；不改变面板展开的原生弹簧与时序。

音量面板内的两个选中块直接使用同一原生普通高亮构造器，避免三段式额外经过仅供 QS 宿主使用的主题过渡层。高亮材质的匹配条件要求同时提供 `TileViewFlag.Toggleable` 与 `TileViewFlag.Active`；只提供 Active 会落到透明的默认状态。系统刷新 enabled／selected 状态后，在绘制前恢复这两个状态，并在选中块布局完成后刷新原生材质路径；原生指示器的位移、缩放和拖动仍由三段式组件负责。

面板关闭时，原侧边按钮及快捷区同步读取原主音量条及父容器的透明度。关闭期间已淡出的部分保持淡出，避免原生移除动画在结束时把行透明度重置为 1，导致原按钮在最终隐藏前闪回或残留。

## 音量条与材质细节

音量条宽度同时作用于原生背景、进度和测量最小宽度，保留当前值与静止值之间的按压变形比例。只有参数发生变化时才刷新派生几何，并保留动画当前姿态；普通测量和状态更新不会反复重置按压动画。

长度通过原生 RecyclerView 视口调整，保留测得的标签、留白和溢出开销。音量行与滑条容器的高度、负顶部边距继续由原生侧边进度溢出和面板交接逻辑管理。

圆角修改背景和进度的原生基础几何，同时调整相应的垂直留白，避免圆角变化导致音量条端点漂移。原生材质宿主继续产生平滑路径、按压轮廓与高光；模糊提交使用宿主自身的密度和当前动画半径，保留其形状提供器。背景混色通过原生材质管线提交一次，原生进度色不变。展开快捷按钮在首次布局前读取已设置的布局尺寸计算圆角，挂载或尺寸改变后重新提交原生材质与形状，避免零尺寸把圆角缓存为 0。免打扰底座的点击涟漪沿用相同圆角，内部选中块保持控制中心原生样式；纯色背景仅修改圆角时同步调整原始形状，绘制后还原，保证圆角减小至 0 也生效。

原生缓存材质在动画中会绕过 `ViewBlurProxy` 直接更新颜色、高光与描边圆角。Hook 同时覆盖这些缓存提交入口，并在提交后恢复原始配置，避免原生动画覆盖自定义混色和圆角；异常路径同样还原。

音量条与按钮的原生模糊配置共用一组参数；面板背景保留单独参数。它们与控制中心和通知材质独立。非模糊背景保留原始 Drawable，自定义关闭后恢复原始绘制。设置关闭时恢复保存的布局、基础宽度、半径和留白。

## 验证范围

- 紧凑面板初始化回归：原生材质构建器的协变返回与合成桥接方法同时存在时，按 `QSDrawableBuilder.build(View, boolean, Integer)` 精确签名调用；原生快捷组件构造失败且面板背景为空时，清理不会再抛空指针并掩盖原始错误。
- `VolumeSettingsTest`：配置兼容与边界、左右锚点、横屏及窄窗口限位、物理坐标与动画位移换算。
- `python3 scripts/check_effects.py --only VolumePanelCheck`：执行实际 Hook 回调，检查原生展开不被取消、原生对象与数据源保留、动画终点、按内容包裹的卡片高度、可见条间距与四周留白相等、单条为四格快捷区预留空间、不同主音量条长度与宽度继承、横向展开不改变可见顶部、三段式原生组件与模式 API 委托、免打扰原生控制和图标资源、免打扰切换中间帧与快速反向衔接、外部状态更新及动画清理、无振动器与实体拨杆限制、标题/设置/标签持续隐藏及可见性恢复、按钮正方形及与实际条宽同步、共享材质、展开快捷按钮实际模糊／纯色背景的 ARGB 与 0／18／64 dp 圆角、首次布局与挂载后的材质刷新、展开／反向／归零材质阶段与重复帧去重、缓存颜色及描边圆角提交与异常恢复、相同起止几何跳过临时写入、原生填充选中块与监听器清理、仅改圆角时的原始形状及异常恢复、按压比例、触摸分发和收起后的侧边尺寸恢复，以及宽度动画的起点、中间帧、终点、反向收起、异常恢复与帧观察器清理。
- `python3 scripts/check_volume_native.py /path/to/SystemUI.apk`：使用 androguard 检查采集固件中的反射目标，并确认原生音量行动画仍调用所接入的几何方法和原生时长解析器；检查原生三段式的组件、状态、材质与动画清理接口；解析资源表及当前系统磁贴代码，核对声音／免打扰图标的来源。

这些检查验证代码行为和固件符号，不证明真机视觉表现。仍需在目标固件检查展开/收起的连续性、动画中再次按音量键或点击外部、横竖屏、应用音量行更新、锁屏、拖动与安全音量提示，以及模糊后端的实际边界。
