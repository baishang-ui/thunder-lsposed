# 功能设置排版

按用户指定的样式级别设置同级开关，不添加页面级父开关。关闭样式时恢复该范围的系统默认并收起参数，保留原参数以供再次开启。

- 流体云：流体云样式（胶囊、展开卡片、应用色）、锁屏样式、通知中心样式。
- 通控中心：背景、通知条样式（卡片、列表与横幅）、磁贴样式（1×1、1×2、音量亮度条、音乐磁贴）。
- 音量面板：面板样式（动画、展开、尺寸、音量条和面板材质）。
- 状态栏、手势条保留各自功能分组，功能修改仍由开关展开。

两端使用相同配置和显隐条件，独立 App 使用现有 Miuix 卡片与 LiquidToggle，宿主页面使用原生 COUI Preference。新增开关影响实际 Hook，配置导入导出保留参数并迁移旧配置；旧修改自动映射到相应分组。

验收：分别关闭每组，只恢复该组；开关状态跨页面、跨入口、重启后保持；旧配置迁移保持现有效果；构建、单元测试、相关 Hook fixtures 通过。
