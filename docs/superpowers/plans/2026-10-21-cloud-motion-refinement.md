# 流体云动画细化实施计划

**目标：** 在已确认的统一对象方案上修复胶囊入退场变形，按用户指定顺序展开/收起多张卡片，增加展开位置调整。

**架构：** 原生业务时钟与挂载保持不变；胶囊使用测量后的稳定尺寸与等比入退场，淡出不缩成一点。首卡保持现有 Body，其他卡片作为同一窗口内的原生材质子层，按共享时钟分阶段运动。展开卡片配置水平和垂直 dp 偏移，整个卡片组同步平移，绘制和输入共用几何。

**约束：** 保留现有未提交成果；设置页使用现有 MIUIx / Liquid Glass，系统设置沿用 COUI schema；原生 Hook 不受本项目控件限制。沿用已有用户批准设计，本轮按用户给出的具体时序直接实施。

- [ ] 回归先复现：胶囊退场不应成为 1px；瞬时 Drawable 宽度不应污染稳定锚点；三卡展开/收起顺序及反向连续性。
- [ ] 修复胶囊尺寸来源、入退场等比压缩与透明度，阻止布局回调重定向为瞬时目标。
- [ ] 所有卡片接入同一窗口，首卡先展开、后续向下依次展开；先收其他卡到首卡背后，再收首卡。保留触摸、可访问性与清理。
- [ ] 增加展开位置开关及 X/Y 偏移，覆盖独立设置、系统设置、Provider、HookConfig、导入导出及旧版本迁移。
- [ ] 运行专项及完整主机回归、Android 构建和单测；已授权手机安装、日志和录屏检查，明确未触发的模板。
