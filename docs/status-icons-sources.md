# 状态栏图标来源

当前 iOS 风格以用户提供的 `双排信号状态栏模块C16.zip` 为可见图形和图标种类基准。用户提供的 C17 参考包 仅用于核对 C17 的信号画布与资源拆分方式，不提供最终图标的轮廓。两个压缩包中的安装、挂载脚本均不执行，也不随应用打包。

`app/src/main/assets/icons/theme-reference` 保存 54 个原图或适配资源及来源清单。每项记录第一包中的素材分类、APK 内资源路径、资源名、原始二进制 XML SHA-256、路径摘要和适配说明。`scripts/import_theme_icons.py` 通过 Android SDK 的 aapt2 读取两个压缩包；`scripts/generate_status_drawables.py` 生成实际编译资源和白名单。所有可见 pathData 均来自第一包，没有沿用第二包的描边或自行补画缺少的图标。

蜂窝信号保留第一包的上排圆角递增柱和下排圆角短条，按 C17 原生主、副卡资源拆成独立图层，各有 0–4 格，组合为 25 种双卡状态。第一包下排部分固定亮度改为由副卡当前强度决定。单卡资源只使用上排；无服务使用第一包的灰色短条。两排共用 19 × 16 viewport，叠加后不会重复绘制另一张卡。

普通状态图标、Wi-Fi、横向电池和蓝牙电池统一改用第一包的路径。第一包没有的高性能、流量节省、竖向电池、独立电池装饰和 ADB 图标，已从替换白名单和当前素材中删除，交由系统提供。透明角标替换按用户补充要求保留：Wi-Fi / 信号角标、代数、上下行箭头、HD / VoLTE / VoWiFi 与漫游标记继续隐藏。

图标可见高度按用户截图统一到约 14dp，左右各留 3.25dp，配合电池前 4dp 间隔形成约 7–8dp 的视觉间距，状态栏继续增加 4dp；横向电池保持原图比例调整为总宽 32dp、总高约 18.92dp，可见主体约 15.48dp 高。尺寸测量与适配参数见 `status-icons-sizing.json`。去掉 C16 包内用于旧布局的 5dp 外部 inset，统一由项目留白处理。横向电池沿用第一包的 93 × 55 轮廓，主体右边界为 x=85；背景和进度共用原始 93 × 55 画布及上下留白，水平和垂直使用相同的放大系数，保持原图的修长比例；百分比在主体内居中，两层保持相同的原生边界，清除系统重复内缩，进度包含主体和电池头，100% 完整覆盖背景；内部数字使用系统设置选定的字体并加粗，不随模块打包字体；电量与充电逻辑由系统负责。

实际资源离线预览见 [status-icons-preview.png](status-icons-preview.png)，实现与验证见 [状态栏资源方案](status-icons-rendering.md)。Apple 参考、旧 SVG 和早期画布属于历史研究，不参与当前替换。原包素材仍归原作者所有，项目许可证不重新授权这些素材；声明见根目录 `THIRD_PARTY.md`。
